# dotfiles

Configuración personal de mi escritorio en Arch Linux + Hyprland.

## Contenido (`.config/`)
- **hypr** — compositor Hyprland (config en Lua 0.55+), keybinds, monitores, arranque.
- **OkPanel** — temas/config de la barra (el proyecto vive en la rama `master`).
- **kitty** — terminal. **rofi** — launcher. **wal** — pywal (color dinámico).
- **yazi**, **ranger** — gestores de archivos. **nvim** — editor.
- **cava**, **btop**, **fastfetch** — visualización/monitoreo. **cliphist** — portapapeles.

## Dotfiles de `~`
`.zshrc`, `.zprofile`, `.bashrc`, `.gitconfig`.

> Los secretos (API keys, llaves SSH, `.secret.env`) están fuera del repo por diseño (ver `.gitignore`).
